# Documentation (`docs/`)

## What Belongs Here
- Architecture specifications, UI design specifications, and threat models.
- Implementation phase roadmaps (`phases/PHASE-0.md` through `PHASE-7.md`).
- Project status tracker (`STATUS.md`) and append-only build history (`BUILD_LOG.md`).
- Component failure modes and fallback mappings (`FAILURE_MODES.md`).
- Architecture Decision Records (`decisions/ADR-xxxx.md`).
- Unresolved architectural or specification gaps (`OPEN_QUESTIONS.md`).

## What Must NEVER Go Here
- Real client documents or extracted protected health information (PHI).
- Production API keys, service credentials, or internal environment IP dumps.
- Ad-hoc, unchecked assumptions modifying the core architecture without an ADR.
