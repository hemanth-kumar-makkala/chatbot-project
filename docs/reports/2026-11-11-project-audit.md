### 3.1 Model & Pipeline Failures (Proven in `docs/reports/2026-11-05-model-comparison.md`)
1. **`Q1` Broad Overview Question Refuses Across All 3 Models (`PIPELINE FAILURE`):**
   - **Evidence:** `docs/reports/2026-11-05-model-comparison.md:34, 66-70`, `docs/BUILD_LOG.md:3094-3101` (`2026-11-05`).
   - **Symptom:** Asking *"What is this document about?"* refuses (`status="refusal"`, `evidence_state="WEAK"`) on `qwen3-vl:4b`, `beam:cloud`, and `mistral-large-4-1t-a52b`.
   - **Root Cause:** `node_route` (`backend/app/core/graph.py:349-351`) checks `_BROAD_OVERVIEW_RE` before invoking the router LLM and returns `route="clarify"` only when `active_document_count > 1` **and** `not runtime.context.conversation_history`. When a query instead enters `retrieve` → `rerank` → `assess_evidence` (`backend/app/core/graph.py:664-920`), broad phrasing produces low cross-encoder reranker scores (`< 0.10` threshold in `desktop-gpu.yaml:22`), triggering `evidence_state="WEAK"` refusal.
2. **`Q4` Source Mixing Across Documents (`MODEL + PIPELINE FAILURE`):**
   - **Evidence:** `docs/reports/2026-11-05-model-comparison.md:37, 71-75`, `docs/BUILD_LOG.md:3084-3092` (`2026-11-05`).
   - **Symptom:** Asking *"What documents are required for an urgent MRI lumbar spine prior authorization?"* fails on all 3 models (`qwen3-vl:4b` refuses after quote validation failure; `beam:cloud` and `mistral-large-4-1t-a52b` answer *"clinical consultation notes and imaging requisition"*).
   - **Root Cause:** Hybrid retrieval supplies top-5 chunks from both `prior_auth_guide.pdf` (which states *"recent clinical notes (within 30 days), conservative therapy history, and the ordering provider's NPI"*) and `faint_fax_2page.pdf` (whose cover sheet mentions *"clinical consultation notes and imaging requisition"*). `node_retrieve` does not isolate policy documents from fax intake sheets, and `node_validate` (`backend/app/core/graph.py:1295-1460`) only checks that the single `quoted_span` is a substring of one cited chunk (`faint_fax_2page.pdf`), leaving unquoted claims or mixed-document context unblocked.
3. **Token Ceiling Truncation on `short` Mode for Reasoning / Verbose Cloud Models (`MODEL + CONFIG WEAKNESS`):**
   - **Evidence:** `docs/BUILD_LOG.md:3137-3142` (`2026-11-05`), `backend/app/core/guards/output_guards.py:21-26`, `backend/app/core/graph.py:923-956`.
   - **Symptom:** `MAX_TOKENS_SHORT = 150` (`backend/app/core/guards/output_guards.py:22`) caused JSON truncation (`Unterminated string`) on `beam:cloud` until per-model generation ceilings (`_MODEL_GENERATION_TOKEN_LIMITS`) were raised to `512` for `beam:cloud` and `300` for `mistral-large-4-1t-a52b` (`backend/app/core/graph.py:926-938`). However, the post-generation output guard `check_answer_token_ceiling` (`backend/app/core/guards/output_guards.py:67-81`) still enforces a hard `150`-word limit on `answer_mode="short"`, which can reject valid multi-item short answers if the router selects `short` instead of `explain`.
4. **Local `qwen3-vl:4b` Fax Extraction Misses Handwritten & Faint Fields (`MODEL WEAKNESS`):**
   - **Evidence:** `docs/reports/2026-11-05-model-comparison.md:88-105`, `evals/reports/phase4_baseline.json`.
   - **Symptom:** On the 3-fax benchmark (28 fields), `qwen3-vl:4b` extracts **19/28 (67.9%)** vs `mistral-large-4-1t-a52b`'s **23/28 (82.1%)**. Specifically, `qwen3-vl:4b` misses cursive `prescriber_signature` (`"Dr. E. Reed"`) on `invalid_npi_fax.pdf` and misses `facility_location`, `referring_phone`, and `ordering_physician` on `faint_fax_2page.pdf` (`docs/reports/2026-11-05-model-comparison.md:100-103`).
