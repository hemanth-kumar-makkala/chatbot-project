# Antigravity Rules & Workflows (`.agents/`)

## What Belongs Here
- System rules governing Antigravity pair programming sessions (`rules/`).
- Slash command workflow specifications (`workflows/`).
- System invariants, architectural boundary constraints, coding standards, and PHI guardrail definitions.

## What Must NEVER Go Here
- Application source code or runtime business logic.
- Production secrets, API credentials, or environment variables.
- Real client documents, test fixtures, or PHI data.
